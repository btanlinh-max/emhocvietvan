# Em Tả Con Vật

Web giúp học sinh lớp 4 học viết bài văn tả con vật theo 5 bước: chọn con vật, quan sát và tìm ý, lập dàn ý, viết bài, chữa bài.

AI nhận xét dùng **Gemini API** của Google.

## Cách dùng

1. Mở web, bấm **Cài đặt AI**.
2. Dán API key lấy ở [aistudio.google.com](https://aistudio.google.com) (Get API key → Create API key), rồi bấm **Kiểm tra và lưu**.
3. Key chỉ lưu trên trình duyệt của máy đó. Mỗi máy dán key một lần.

Không có key thì học sinh vẫn dùng được mọi phần, kể cả Kiểm tra nhanh. Chỉ phần "Cô AI nhận xét" cần key.
